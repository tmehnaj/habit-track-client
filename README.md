## Project_Name: Habit track

A simple and user-friendly Habit Tracker Web App to help users build streaks, stay consistent, and monitor daily habits.

## Live Site

https://your-live-site-url.com


## Features

* Email/Password + Google Authentication

* Add, Update, Delete, and View Habits

* Mark habits as complete (No duplicate same-day entry)

* Streak calculation and 30-day progress bar

* Browse public habits with search & category filters

* Responsive UI with Framer Motion and React Typewritter Effect animations

* Toast/SweetAlert

* Secure protected routes

## Tech Stack
## Frontend
